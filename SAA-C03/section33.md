## 2. 시험 접수 및 준비

- **시험 예약**: AWS Certification 공식 홈페이지 ([aws.amazon.com/certification](https://aws.amazon.com/certification))
- **시험 형식**: 온라인 감독 (PSI / Pearson VUE) 또는 테스트 센터
- **시험 시간**: 130분, 65문제
- **합격 점수**: 720 / 1000 이상

**최종 준비 체크리스트:**
- [ ] 모든 섹션 강의노트 복습
- [ ] AWS 공식 연습 시험 풀기
- [ ] 취약 분야 재확인 (섹션 32 참고)
- [ ] Udemy 연습 시험 풀기
- [ ] AWS Free Tier로 실습
